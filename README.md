# ChromTV Issues

Public issue tracker for ChromTV.

Use this repository to report bugs, request features, or describe playback problems. The app source code lives in a private repository.

## Before you create an issue

- Do not post IPTV usernames, passwords, tokens, private playlist URLs, or personal data.
- If a stream URL is needed for diagnosis, describe the provider/type instead of sharing credentials publicly.
- Include screenshots when they help explain the problem.
- For playback issues, include device, platform, app version, channel name, and what happened.

## Useful issue types

- **Playback problem**: Live TV does not start, buffers, falls back incorrectly, or gives player errors.
- **Bug report**: Something in the app behaves incorrectly.
- **Feature request**: A new idea or improvement for ChromTV.
